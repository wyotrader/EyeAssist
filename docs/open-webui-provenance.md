# Open WebUI provenance

EyeAssist previously used a customized Open WebUI frontend as a donor prototype.
The native EyeAssist frontend now lives in `eyeassist-ui/` and does not retain
the Open WebUI package namespace or donor UI modules.

- Original upstream project: Open WebUI
- Upstream repository: https://github.com/open-webui/open-webui.git
- Vendor baseline commit: `6f8881526c5c1e8abc03e8de1dda2d8d9f58e6af`
- EyeAssist source branch at migration: `eyeassist-main`
- Baseline commit description: `Add EyeAssist system health dashboard`
- Monorepo migration date: 2026-09-04

The complete donor UI is preserved outside this candidate at
`/home/jwhitman/eyeassist-preservation-staging/eyeassist-ui-complete.tar.zst`.
Do not modify that archive.

Retain this document for historical provenance. If any Open WebUI-derived source
is copied back into EyeAssist later, preserve the applicable Open WebUI license
and copyright notices with that material.
